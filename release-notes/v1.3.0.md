# 🚀 Smart Word Definition Popup v1.3.0

**Release Date:** 2026-06-10

## ✨ What's New

### Auto-Update Support
- 📦 Added `@updateURL` and `@downloadURL` headers so Tampermonkey and Violentmonkey can auto-update the script from the GitHub raw URL — no manual reinstallation needed.

### Performance: Eliminated DOM Thrashing in Color Parsing
- ⚡ Replaced the per-call `appendChild`/`removeChild` cycle in `parseColor()` with a **single cached hidden element** (`_colorParserEl`) appended once at startup.
- 🚀 Added **fast-path parsing** for common `rgb()`, `rgba()`, and `#rrggbb` formats via regex — most color values are resolved without touching the DOM at all.
- 🔁 Color parsing during theme detection (which runs on every selection) is now significantly faster, especially on content-heavy pages.

### Smooth Fade Transitions Fixed
- 🎨 Replaced `display: none` ↔ `display: block` toggling with `visibility: hidden` ↔ `visibility: visible`.
- ✨ The popup now **properly fades in and out** with `opacity` + `visibility` transitions (`0.15s ease`) — previously the `display: none` prevented any CSS transition from animating.
- 📐 Because the element remains in layout flow while hidden, `getBoundingClientRect()` returns accurate dimensions, making **popup positioning more reliable** from the first display.

## 🐛 Bug Fixes

- Fixed the popup appearing to "snap" open rather than fading in on some browsers.
- Fixed incorrect popup positioning on first show (caused by zero-size bounding rect when `display: none`).

## 🔧 Automation Improvements

- Fixed GitHub Actions workflow path filters — previously pointed to the wrong file path (missing `word-definition-popup/` subdirectory prefix), so the release and validate-PR workflows would never trigger.
- Fixed version extraction regex (`\s{6}` → `\s+`) to be resilient to spacing changes in the userscript header.
- Added version validation step in the release workflow — aborts early with a clear error if the version cannot be parsed.
- Added strict semver **greater-than comparison** in the PR validation workflow — ensures the PR version is truly higher than the base branch version, not just different.
- Fixed all file paths in workflows to correctly reference assets and release notes inside the `word-definition-popup/` subdirectory.
