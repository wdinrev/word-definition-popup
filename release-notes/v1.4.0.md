# 🚀 Smart Word Definition Popup v1.4.0

**Release Date:** 2026-10-06

## ✨ What's New

### 🐛 Fixed: "Stuck in Loading..." Issue Resolved
- Replaced the single-API dependency on `api.dictionaryapi.dev` (which suffers from frequent downtime and Cloudflare 522 connection timeouts) with a resilient multi-tier dictionary architecture.
- **Primary source**: Wikimedia Wiktionary REST API (`en.wiktionary.org`), powered by Wikimedia's global edge network (~200–300ms latency, 99.99% uptime).
- **Secondary fallback**: Datamuse API (`api.datamuse.com`) for WordNet definitions.
- **Tertiary fallback**: Free Dictionary API (`api.dictionaryapi.dev`) for phonetics and alternative definitions if available online.
- Added strict 3500ms timeouts on all request layers — the popup will **never hang in a loading state indefinitely**.

### ⚡ Instant In-Memory Cache
- Added an in-memory `Map` cache for definitions.
- Re-selecting or looking up a previously viewed word displays the popup **instantly in 0ms** without any network round-trip.

### 🚫 Strict CSP Compatibility & Performance
- Removed the external `<link>` stylesheet injection from Google Fonts.
- Switched to a robust system monospace font stack (`'IBM Plex Mono', ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, 'Liberation Mono', monospace`).
- Eliminates browser console Content Security Policy (CSP) violations on strict websites (GitHub, Twitter/X, banking/finance websites, etc.) and avoids network round-trips on initial page load.

### ✂️ Smarter Text Selection & Interaction
- Text selection automatically trims enclosing quotation marks, commas, parentheses, and trailing punctuation, so accidentally highlighting punctuation no longer fails the lookup.
- Optimized debounce delay to 250ms for snappy responsiveness.
- Added request ID tracking to discard outdated in-flight responses if a user selects a new word or dismisses the popup.

### 👤 Author & Repository Cutover
- Updated author to `wdinrev`.
- Updated all homepage, update, download, and repository URLs to `wdinrev/word-definition-popup`.
- License updated to `wdinrev`.

### 🔄 GreasyFork Synchronization
